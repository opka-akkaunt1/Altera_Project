Мониторинг репозитория через API
Демонстрационный проект

Задача
Команде нужна компактная карточка публичного репозитория.

Что реализовано
Подключил GitHub REST API, обработку ошибок и автономный тестовый ответ для презентаций.

Сценарий для показа
Введите публичный репозиторий и нажмите «Запросить GitHub API». Для просмотра без интернета откройте тестовый ответ.
