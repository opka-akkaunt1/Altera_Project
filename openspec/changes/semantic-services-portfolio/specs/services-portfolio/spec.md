## ADDED Requirements

### Requirement: Порядок разделов главной страницы

Главная страница MUST представить шесть направлений услуг и этапы работы перед ознакомительным каталогом.

#### Scenario: Заказчик выбирает услугу

- **GIVEN** заказчик открыл главную страницу
- **WHEN** он выбирает направление в разделе услуг
- **THEN** сайт позволяет перейти к подходящим примерам в каталоге.

### Requirement: Читаемые страницы демонстраций

Каждая страница проекта MUST иметь основной заголовок и содержимое в семантической HTML-разметке. Оформление и сценарии исходной версии хранятся в отдельных файлах.

#### Scenario: Просмотр с выключенным JavaScript

- **GIVEN** JavaScript отключён в браузере
- **WHEN** заказчик открывает страницу проекта
- **THEN** видны заголовок, основной интерфейс и начальные данные.

#### Scenario: Лендинг отправлен одним файлом

- **GIVEN** автономный файл лендинга сохранён отдельно
- **WHEN** заказчик открывает его без сети
- **THEN** доступны оформление, фотография и тестовая отправка формы.

### Requirement: Интеграции в портфолио

Портфолио MUST содержать демо формирования запроса Битрикс24 и просмотр публичных данных через GitHub API.

#### Scenario: Повторная отправка заявки в демонстрации CRM

- **GIVEN** тестовая сделка с теми же полями уже создана
- **WHEN** пользователь повторяет запрос
- **THEN** демо показывает существующую сделку.

#### Scenario: Просмотр открытых данных GitHub

- **GIVEN** введено имя существующего публичного репозитория и доступна сеть
- **WHEN** пользователь запрашивает данные GitHub
- **THEN** витрина показывает название репозитория, ветку и показатели из ответа.
