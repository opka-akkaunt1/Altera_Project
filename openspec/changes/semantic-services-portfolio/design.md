## Context

Сайт помогает заказчику выбрать услугу. Примеры показывают интерфейс и способ решения типовых задач.

## Decisions

- Статическая структура подходит для размещения на обычном хостинге и локального просмотра.
- HTML отвечает за структуру, CSS за оформление, JavaScript за действия. Поведение каждого проекта хранится рядом с его страницей.
- У каждого кейса есть карточка, два скриншота и копируемый текст.
- Для пересылки предусмотрен один автономный HTML лендинга.

## Future Work

Подключение рабочих аккаунтов CRM и Telegram, хранение данных, идентификация пользователей, оплата и интеграции с AI добавляются по требованиям конкретного заказчика.
