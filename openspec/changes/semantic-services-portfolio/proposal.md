## Why

Заказчику нужно сначала понять, какие задачи можно заказать, и затем посмотреть примеры. Исходники сайта должны быть пригодны для ручного редактирования.

## What Changes

- Главная показывает услуги, этапы работы и каталог демонстраций.
- Страницы демонстраций используют семантический HTML и отдельные файлы стилей и поведения.
- Автономный лендинг поставляется отдельным артефактом для пересылки.
- В портфолио входят 14 кейсов со скриншотами, включая Битрикс24 и GitHub API.

## Capabilities

- `services-portfolio` — витрина услуг, каталог и браузерные демонстрации.

## Impact

Изменяются статические страницы и исходники портфолио. Битрикс24 и остальные закрытые сервисы пока показаны на тестовых данных. GitHub использует публичный REST API.
