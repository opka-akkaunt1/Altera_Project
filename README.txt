ПОРТФОЛИО ЦИФРОВЫХ ПРОЕКТОВ

Распакуйте ZIP целиком и откройте index.html в браузере. Установка и интернет не нужны.
Держите папку целиком для локального просмотра. Для пересылки одного файла используйте отдельный forma-landing.html.

Исходники: HTML хранит разметку, portfolio.css — стили, demo-helpers.js — общие функции. В каждой папке interaction.js отвечает за действия конкретного кейса.
Спецификация и сценарии приёмки находятся в openspec/. План доработки — в docs/superpowers/plans/.

В каждой папке
  index.html — интерактивное демо
  case.html — карточка проекта со ссылками
  case.txt — текст кейса для публикации
  01-screen.png — исходный экран
  02-result.png — результат действия

Обновите страницу, чтобы начать сценарий заново.
Боты, сервисы, платежи и AI показаны на тестовых данных. Telegram, платёжный шлюз, CRM и AI API не подключены.
